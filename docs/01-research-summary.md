# 01 · 研究摘要：現況架構與使用者優缺點（公開版）

> 依據：團隊 Slack 討論、測試與驗收簡報、現行 App 程式碼與 issue（2026-08～10）。
> 公開版已移除合作機構名稱、人員、內部連結與使用量數字；完整證據版（含每條發現的來源）以私人文件提供給專案成員。
> 代碼對應：`K-*` 保留的優點、`F-*` 要修的缺點、`Q*` 使用者需求、`D*` 設計啟示，與 [`02-user-flow.md`](02-user-flow.md) 一致。

## 1. 現況軟硬體架構（as-is）

| 層 | 現況 |
|---|---|
| ① 收音硬體 | 胸前 BodyCam（自建 Wi-Fi AP、SD 卡、按鍵開錄）；手機語音備忘錄分享匯入；規劃中的藍牙電子紙識別證（先選個案再錄） |
| ② 行動 App | React SPA＋Capacitor 原生殼（iOS／Android），底部 5 顆純圖示導覽，標準版／易讀版雙模式 |
| ③ Web | 同一份程式碼建置的網頁版 |
| ④ 後端 | .NET API、PostgreSQL、Blob；SignalR 推送轉譯完成 |
| ⑤ 語音轉文字 | 雲端 STT（zh-TW），支援多段錄音合併 |
| ⑥ LLM | 雲端 LLM：錄音 → 護理紀錄；**護理紀錄 → 護理計畫、家屬衛教**（計畫與衛教只吃紀錄全文）；衛教可翻譯印尼／泰／越文 |
| ⑦ 人工審閱 | 全人評估 16 表燈號；AI 文字可直接編輯 |
| ⑧ 匯出 | 訪視紀錄單 PDF（影像式）、LINE 分享衛教；院方 HIS 推入 |

**關鍵結構問題**：PDF 與錄音是兩條互不相通的管線——PDF 只能在新收案時夾帶、只產生評估草稿，**無法產出三份文件**；錄音要經硬體切網傳檔、轉譯、匹配個案後才能產出紀錄，計畫與衛教再從紀錄衍生。

## 2. 現況使用流程（錄音 → 三份可貼上的文字）

約 **8 個畫面、25 次點擊、2 次手動切換 Wi-Fi、3 次前景等待**；護理紀錄與護理計畫頁**沒有複製按鈕**（要 MORE → 長按 → 全選 → 複製 → 返回）。PDF 路徑約 63 次互動仍拿不到三份輸出。

## 4. 使用者缺點（要修）— Top 10

| ID | 缺點 | 新設計的對策 |
|---|---|---|
| F-A4 | 語音不能自動帶入評估，雙重輸入 | 分析時整理評估要點，數值一次確認三份同步 |
| F-B1 | **生命徵象數字轉錯**（例：36.3 → 16.3）；「AI 寫的跟我念的不一樣」 | 「先看這裡」：原句＋▶原音＋唯一合理候選值；AI 不寫數字，由確認值組成 |
| F-A1 | 硬體傳檔要切 Wi-Fi、App 留前景、偶爾卡 0% | 手機或電腦直接錄；硬體檔改為匯入來源之一 |
| F-D3 | 失敗沒有提示或只寫「未知錯誤」、按鈕反灰無說明 | 每一步都有人話錯誤＋一鍵重試，資料留在裝置 |
| F-C1 | 轉譯出現簡體字 | 轉譯後一律 OpenCC 轉台灣正體；輸出再檢查 |
| F-A3 | 三份輸出分散在不同分頁、硬性串聯、同步等待 | 一次分析、三份平行撰寫、同一頁攤開 |
| F-F1 | 夾帶 PDF 建檔失敗；PDF 只能在建檔時上傳 | PDF 隨時可匯入任何個案，直接產出三份 |
| F-A2 | 錄完才對應個案，容易錯、可能是死路 | 先選個案再錄；錄錯可「改到其他個案」並復原 |
| F-D1 | AI 覆寫前不確認、沒有草稿／確認狀態 | 狀態機：AI 草稿 → 已修改 → 已確認；版本只增不刪 |
| F-G2 | AI 生成失敗率偏高、卡在處理中 | 單份失敗隔離、單份重試、背景處理可離開 |

其他缺點：等待看不到進度（F-A7）、逐字稿雜訊與講者不分（F-B2）、英文按鈕與用語不一（F-C3）、沒有複製鈕（F-E1）、輸出只顯示 6 行（F-E2）、字小與導覽不一致（F-J2、F-J3）、首頁主要動作埋在最底（F-J4）、教一次成功率低需陪跑（F-J1）、日誌含個資的風險（F-I1）。

## 5. 使用者需求（節錄）

- Q01 語音帶入的欄位以**黃色底**標示並可確認，不推測、不覆寫。
- Q02 生成護理計畫前先確認今日評估異動，記錄確認人與時間。
- Q03 護理師可自己隨時上傳全人評估 PDF，失敗可以重來。
- Q05 先選個案再收音。
- Q08 護理計畫預設沿用，有新問題才建議新增。
- Q09 衛教可轉發 LINE、翻成外籍看護的語言。
- Q16 易讀大字、柔和警示色。
- Q22 目標：≤20 秒生成、≤3 處修改、一鍵完成。

## 6. 對新 App 的設計啟示（D01–D20 摘要）

1. 單一入口「新紀錄」：PDF、照片、錄音、App 內直錄都可，新舊個案皆適用（D01）。
2. 先選個案再錄音，沒有死路（D02）。
3. 一次產出三份、背景執行、看得到每一步進度（D03）。
4. 每份一顆「確認並複製」，另有「全部確認並複製」（D04）。
5. 數值獨立核對：原句、原音、候選值、人工值優先（D05）。
6. 「AI 草稿 → 審閱 → 確認」狀態機，永不覆寫（D06）。
7. 生成前檢查評估異動（D07）；失敗透明可重試（D08）；PDF 隨時可補（D09）。
8. 繁體與用語鎖定、全中文介面（D10）；結構化模板可依機構調整（D11）。
9. 計畫沿用＋建議新增（D12）；衛教一鍵分享與翻譯（D13）。
10. 三步驟極簡介面、易讀為預設、手機到桌機同等能力（D14–D16）。
11. 逐字稿可對照、隱私預設遮罩、硬體選配化、輕量回饋與採用量測（D17–D20）。
