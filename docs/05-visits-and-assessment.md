# 初次訪視、再次訪視與全人評估

居護師的訪視分兩種。兩種都產出護理紀錄、護理計畫、家屬衛教，差別在計畫怎麼來。

| | 初次訪視（初訪） | 再次訪視（複訪） |
|---|---|---|
| 全人評估 | **要做**：基本資料＋13 張評估表 | 不必做；每半年提醒重新評估 |
| 護理計畫 | **依全人評估擬定**（第 1 版） | 沿用現行計畫，依本次發現調整（第 N 版） |
| 護理紀錄 | 本次病摘＝護理紀錄 | 本次護理紀錄 |
| 家屬衛教 | 依本次重點 | 依本次重點 |

## 1. 流程

**初訪**
1. 個案 → ＋新增個案（姓名等）→ 直接進到個案頁，最上方是「全人評估 0/13」。
2. 在案家逐張填寫（選項都是大按鈕，計分即時算好），每張「儲存，下一張」。可以先錄音，評估回來再補。
3. 今日清單的這筆訪視標「初訪」，並顯示「初次訪視：全人評估 x/13」。
4. 錄音或匯入文件後產生三份：護理紀錄（本次病摘）、護理計畫（依全人評估擬定，問題依據會寫出分數，例如「Braden 12 分（高危險）」）、家屬衛教。
5. 評估還沒填完就產生了計畫：計畫卡會提示「全人評估 x/13：填完後依評估擬定計畫」；填完後顯示「全人評估有更新 → 依評估重新擬定」。

**複訪**
1. 照常錄音或匯入，產生三份；計畫沿用現行版本並依本次發現調整。
2. 個案頁的全人評估卡顯示下次評估日期；超過半年以紅字提醒，打開後可逐張修改，完成後按「完成本次重新評估」，以當天重新起算半年。

系統依個案是否已有完成的訪視自動判斷初訪或複訪；工作台 ⋯ 可以改。

## 2. 13 張評估表

來源：機構雲端硬碟「13項評估表單」。

| # | 表單 | 計分與分級 |
|---|---|---|
| — | 基本資料 | 病歷號碼、出生日期、身分證字號、教育程度、主要照顧者、通訊地址（只存在裝置，不送 AI） |
| 1 | 健康習慣 | 吸菸、飲酒、檳榔、運動 |
| 2 | 疾病史 | 既往病史（複選）、手術史、過敏史；新填時依個案診斷帶入 |
| 3 | 藥物安全 | 多重用藥、遵從性、高風險藥物、成藥／中草藥、用藥清單 |
| 4 | 身體評估 | 身高、體重、體溫、脈搏、呼吸、血壓、疼痛分數、意識、其他發現；新填時帶入上次生命徵象 |
| 5 | Braden 壓傷 | 6 題 6–23 分：≤12 高危險、13–14 中危險、15–16 低危險 |
| 6 | 跌倒（Morse） | 6 題 0–125 分：≥45 高危險、25–44 中度 |
| 7 | ADL（巴氏） | 10 題 0–100 分：0–20 完全依賴、21–60 嚴重、61–90 中度、91–99 輕度、100 獨立 |
| 8 | IADL | 8 項勾選可獨立者：≤3 需大量協助、4–6 部分協助、7–8 可獨立 |
| 9 | 認知（SPMSQ） | 10 題答錯計分：0–2 正常、3–4 輕度、5–7 中度、8–10 重度 |
| 10 | 情緒（BSRS-5） | 5 題 0–20 分：≥15 重度、10–14 中度建議轉介、6–9 輕度；另問自殺意念 |
| 11 | 營養（MNA-SF） | 6 題 0–14 分：12–14 正常、8–11 高風險、0–7 營養不良 |
| 12 | 疼痛 | NPRS 0–10、位置、性質、頻率、緩解因素 |
| 13 | 衰弱（Fried） | 5 項：0 強健、1–2 衰弱前期、≥3 衰弱 |

## 3. 資料與保存

- 全人評估記在個案上（`Patient.assessment`），每張表記下填寫人與時間；修改時舊版本放進修改歷程（只增不刪）。
- 13 張第一次全部完成的日期為基準，半年（182 天）後提醒；重新評估完成後以當天重算。
- 給 AI 的只有評估摘要（分數、分級、失分的項目、病史與用藥），不含姓名、身分證、地址。

## 4. 護理計畫怎麼依評估擬定

產生計畫時帶入評估摘要，依風險轉成護理問題（每項依據寫出分數）：

| 評估結果 | 護理問題 |
|---|---|
| Braden ≤16 | 皮膚完整性受損的危險性 |
| Morse ≥25 | 有跌倒的危險 |
| ADL ≤60 | 自我照顧能力缺失 |
| MNA-SF ≤11 | 營養不均衡：少於身體需要 |
| SPMSQ ≥3 | 記憶／認知功能障礙相關問題 |
| BSRS-5 ≥6 或有自殺意念 | 焦慮／憂鬱／自殺危險 |
| NPRS ≥4 | 疼痛 |
| Fried ≥3 | 衰弱 |
| 多重用藥或高風險藥物 | 藥物使用安全 |

最多 5 個問題（與計畫模板一致），初訪的問題都標「本次新增」。
