# 照護紀錄導出（PDF）

把一次訪視整理成居家護理所 HIS 匯出的「照護紀錄」格式，再加上本 App 產生的護理計畫與家屬衛教，直接產生 PDF，可分享到 LINE 等 App 或下載。

> 參考文件是合作居家護理所 HIS 匯出的照護紀錄（3 頁 A4）。本文件只拆解版面與欄位，不收錄任何個案、人員或病情內容；範例值皆為虛構。

## 2. 加入的內容

在【個案近期使用急診】之後，以相同表格樣式加入：

- 【護理計畫】計畫版本（第 N 版、確認日期）、計畫內容、確認人員
- 【家屬衛教】衛教內容（含機構署名）、確認人員

另加：每頁（封面除外）頁碼「第 N 頁／共 M 頁」；示範個案每頁頂端加註「示範資料・非真實個案」。

## 3. 流程

1. 工作台底部「PDF」按鈕（或 ⋯ →「照護紀錄導出（PDF）」）。
2. 導出面板列出這份 PDF 會包含什麼、還沒填的欄位，可直接補：紀錄來源、服務項目、身高／體重／臂中圍／小腿圍、收案日期、居住所、居住區域、使用資源、近 30 天的非計畫性住院與急診（記在個案上，下次也看得到）。
3. 「確認並產生 PDF」：與「全部確認並複製」同一道關卡（先看這裡沒處理完會擋下並列出），通過後三份一起標成已確認，產生 PDF，並記下導出人員與時間。
4. 產生後：
   - **分享 PDF（LINE、郵件…）**：開系統分享面板，選 LINE 再選聊天室，就把 PDF 檔傳出去（iPhone Safari、Android Chrome、Windows／macOS 的 Chrome 與 Safari 支援）。
   - **下載 PDF**：存到裝置。
   - **開啟預覽**：在新分頁開 PDF。
   - **用 LINE 傳衛教文字給家屬**：開 LINE 的文字分享（只帶衛教文字，不帶病歷內容）。

檔名用遮罩後的姓名（`照護紀錄_陳○蘭_2026-10-03.pdf`），因為檔名會出現在聊天室與檔案清單；PDF 內文是全名。

## 4. 技術

- PDF 在手機或電腦上產生（pdfmake），內容不經過伺服器；離線也能導出。
- 字型：Noto Serif TC（SIL OFL，`public/fonts/OFL.txt`），內文用 Big5 字集子集（約 2.8 MB，第一次導出時下載並快取），標題粗體只含固定標籤的字。PDF 只嵌入用到的字，檔案約數百 KB。
- 版面：`src/export/careRecordPdf.ts`；資料對應：`src/export/careRecord.ts`；分享與下載：`src/export/share.ts`。
- 試用版（分享網頁）：不能開系統分享，改用分享網頁的下載（在 Claude App 會開系統分享面板，可選 LINE）；「用 LINE 傳衛教文字」照常可用。

## 5. 之後可以做

- **逐項評估格式**：分析時多抽出原文件的評估項目（肢體水腫、呼吸音、GCS、進食、排泄、皮膚、口腔…），照護紀錄欄改為「項目：結果。」逐行＋敘述，與 HIS 完全一致。
- **身體測量由語音帶入**：「體重三十六點四公斤」直接填入體重欄（與生命徵象同一套核對規則）。
- **LINE 官方帳號推播**：若要由系統直接傳給家屬（不經手機分享），需機構的 LINE 官方帳號與 Messaging API，且家屬須先加好友；LINE Notify 已停止服務，不能使用。
